# Domain/Rules

This folder contains domain business rules.

## Planned Rules

- `ScoringRules` - Rules for calculating exam scores
- `CriticalQuestionRules` - Rules for critical question validation
- `PassingThresholdRules` - Rules for determining pass/fail
