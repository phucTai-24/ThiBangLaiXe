# Domain/Enums

This folder contains application-level enums.

## Planned Enums
- `ExamStatus` - Status of an exam session (NotStarted, InProgress, Completed, Expired)
- `QuestionDifficulty` - Difficulty level (Easy, Medium, Hard)
- `UserRole` - User roles (Admin, Staff, Instructor, Student)
- `CertificateStatus` - Certificate status (Pending, Issued, Revoked)
- `EntitlementType` - Type of entitlement/package

## Migration
Enums will be moved from `Models/` to this folder in a future phase.
