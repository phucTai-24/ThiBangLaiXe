# Domain/Constants

This folder contains application-level constants.

## Planned Constants
- `ExamConstants` - Exam-related constants (default duration, passing score, etc.)
- `ValidationConstants` - Validation limits (max question length, file size, etc.)
- `ApiConstants` - API-related constants (pagination defaults, cache durations)

## Migration
Hardcoded values will be extracted from Services and Controllers in a future phase.
